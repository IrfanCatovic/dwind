# D-Wind GmbH website

Next.js (App Router) foundation for the D-Wind GmbH corporate site.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects to `/de`.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint

## Locales

- German (default): `/de`
- English: `/en`
